Test App

org.interos.test_app — a platform self-diagnostic

What this app does

It answers the question a developer actually has when an app misbehaves: what does this OS know about the process I am running in? Every value on the app's screen is read from a real kernel source at runtime, and each one is labelled with that source.

Refusals are results

A probe this task is not authorised to make is reported as refused (-1) PermissionDenied together with the capability it would have needed. That is a true and useful answer: it tells you the syscall exists and that authority was withheld, rather than silently reporting a plausible default.

The live interface is rendered by the guest kernel. This page documents the app and shows no values, because nothing here can read the kernel.
