Local path

The Ring 3 app sends a real datagram to 127.0.0.1 and reads it back, comparing the bytes. That exercises the kernel's UDP/IPv4/Ethernet path and the real network device. It proves the local stack works; it does not reach a peer.

The live interface is rendered by the guest kernel. This page documents the app and deliberately shows no invented conversation, node count or signal strength.
